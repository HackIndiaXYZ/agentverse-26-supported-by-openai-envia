# Envia Terminology

- **Envia**: the container platform.
- **Jail**: an isolated workload with a managed lifecycle.
- **Jailfile**: declarative build definition.
- **Jail Image**: reusable, versioned filesystem/configuration artifact.
- **Jailor**: runtime manager for jail lifecycle.
- **Jailhouse**: multi-service application definition and orchestration.
- **Warden**: future distributed workload coordinator.
- **Lockdown**: security policy system.
- **Checkpoint**: explicitly defined saved state.
- **Registry**: image distribution and storage.
- **Agent Run**: first-class workload built on top of jails for controlled AI-agent execution.
- **Execution Ledger**: append-only record of an Agent Run.
- **Change Gate**: approval boundary between produced and trusted artifacts.
- **Recovery Loop**: bounded, auditable repair-and-rerun workflow.

Familiar terms such as mount, network, port, log, volume, and cache remain unchanged where clarity is more important than branding.
