# Envia

Envia gives you hermetic, reproducible sandboxes for AI agent runs.

Available MCP tools (via the `envia` server):
- `envia_sandbox_create` — create a sandbox
- `envia_sandbox_list` / `envia_sandbox_get` — inspect
- `envia_sandbox_run` — run a command, capture output
- `envia_sandbox_write_file` / `envia_sandbox_read_file` / `envia_sandbox_list_files`
- `envia_sandbox_snapshot` / `envia_sandbox_restore`
- `envia_sandbox_destroy`
- `envia_audit_log`

Ask me to create a sandbox and run commands in it; I will keep the run hermetic.
